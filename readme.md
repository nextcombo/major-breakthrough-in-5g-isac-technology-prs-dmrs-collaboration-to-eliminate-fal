The recent research paper published at the 2024 IEEE Global Communications Conference (GLOBECOM), titled "Research on Integrated Perception and Communication (ISAC) Systems Based on PRS and PDSCH," proposes innovative solutions that successfully tackle the "false alarm targets" issue when using PRS for perception, providing a feasible path for the practical application of 5G ISAC.  
Abstract From an industrial perspective, the core requirement of integrated perception and communication (ISAC) is to add perception services to existing infrastructure while minimizing network modifications and fully utilizing existing resources. This study focuses on the signals defined by 3GPP for the 5G New Radio (NR) and explores the technical potential of using positioning reference signal (PRS) for perception and physical downlink shared channel (PDSCH) for communication. However, a critical challenge when using PRS for perception is the "false alarm target." To address this, the study proposes two innovative methods based on different PRS tooth sizes, utilizing demodulation reference signal (DMRS) in the PDSCH to eliminate false alarm targets; simultaneously constructing a resource allocation model for PRS and PDSCH to achieve Pareto optimal performance in communication and perception without false alarm targets. Simulation results show that the joint application of DMRS and PRS can effectively remove false alarm targets, and efficient time-frequency resource allocation can help ISAC systems reach Pareto optimal performance.
Introduction: ISAC's Vision and Potential of 6G Signal Perception
The sixth-generation (6G) wireless network aims to revolutionize communication paradigms by integrating perception capabilities. ISAC technology enables a single network to simultaneously carry out enhanced environmental monitoring, real-time target tracking, smart city dispatching, among other diverse tasks, becoming the core support for the Internet of Things (IoT). The reference signal in 5G NR, due to its ideal autocorrelation, cross-correlation characteristics, and strong noise resistance, becomes an optimal choice for ISAC systems—reusing these signals without the need for additional dedicated hardware significantly reduces hardware costs, streamlines system implementation, and decreases computational complexity.
Among many 5G reference signals, the Positioning Reference Signal (PRS) introduced in Release 16 of 3GPP stands out: it adopts an interleaved or diagonal resource element (RE) mapping pattern, with high RE density, abundant time-frequency resources, and flexible configurations, supporting four frequency comb modes (Comb 2/4/6/12) and five time domain symbol configurations, allowing up to 272 physical resource blocks (PRBs) to be occupied, meeting the perception accuracy requirements of different scenarios. However, the design intention of PRS was not for perception but for positioning, and its structure contains empty REs that cause distance estimation ambiguity, leading to "false alarm targets"—those false targets are highly similar to the true target signal features and difficult to distinguish, severely affecting the reliability of perception.
Existing solutions have obvious deficiencies: some rely on multiple reference signals for collaboration, which can interfere with PDSCH data transmission; some can alleviate ambiguity but significantly reduce the maximum detection range and cannot flexibly choose the size of PRS comb patterns. Therefore, there is a pressing need for a solution that complies with 3GPP standards and is compatible with existing 5G networks to eliminate false alarm targets. This study proposes an innovative solution based on DMRS.
Core Method: Dual Algorithms for De-jittering + Resource Optimization, Balancing Compatibility and Performance. The core idea of this research is to reuse the DMRS originally used in PDSCH for channel estimation, collaborate with PRS to complete the perception task, and achieve a balance between communication and perception performance through resource optimization. This process fully complies with the 3GPP TS 38.211/38.214 standards without requiring modifications to base station configurations.
1. The false alarm elimination algorithm for different scenarios is designed based on the four comb sizes of PRS, and two complementary algorithms are researched and designed to precisely eliminate false alarm targets.
✧  
Algorithm 1 (Applicable to Comb Coils 2/4): First, independently estimate the distance for PRS and DMRS, obtaining two sets of estimated vectors. Since the false alarm positions of PRS and DMRS are complementary - one position will have a false alarm while the other usually does not, by performing Hadamard product (element-wise multiplication) on these two sets of vectors, the false alarm peaks can be directly suppressed, accurately preserving the true target signal. This algorithm can fully maintain the original distance resolution and maximum unambiguous detection range of PRS without performance degradation. If the bandwidth of PRS differs from that of PDSCH, adjusting the number of IFFT points can ensure vector size consistency.
✧  
Algorithm 2 (Applicable for Combtooth 6/12): When the combtooth is large, the false alarm targets of PRS and DMRS will overlap, limiting the effect of multiplication. The algorithm first performs a time-domain symbol summation and normalization on the received signals of PRS and DMRS to balance their roles in the Inverse Fast Fourier Transform (IFFT), then performs an IFFT operation on the summed signal. This processing can break the signal periodicity of PRS and DMRS, suppressing false peaks, thereby clearly distinguishing between true and false targets. If the bandwidth differs, zero padding can be used to match the vector sizes of both signals.
2. Pareto Optimal Resource Allocation in 5G
Due to the inability of perception and communication symbols to share the same resource element (RE) within the resource grid, this study has constructed an optimization model for resource allocation between PRS and PDSCH. Targeting communication throughput, distance resolution, and speed resolution, a weight coefficient is introduced (adjusted according to application priority), and by optimizing the allocation ratio of physical resource blocks (PRBs) and time slots, a Pareto optimal solution that satisfies the constraints of (for communication weight, target k distance, speed resolution weight) is found.
Simulation Verification: Complete False Alarm Elimination, Resource Allocation Optimized
The simulation was conducted using the Matlab 5G toolbox, fully compatible with 3GPP standards. The simulation scenario was set as follows: carrier frequency at 28GHz, subcarrier spacing of 120kHz, two targets with double-base station distances of 1057m and 1242m respectively, both moving at 5m/s, and employing 16-QAM modulation.
Results show: When only PRS is used, both sizes of comb teeth (4 and 12) resulted in a large number of false alarm targets, severely interfering with the accurate recognition of real targets; however, after adopting a joint algorithm of PRS+DMRS, all false alarm targets were eliminated, and the distance estimation of real targets became precise and reliable. In terms of resource allocation, when the maximum available PRS resources are 272 PRBs and 80 time slots, assigning 6 time slots and 12 PRBs to PRS, and the rest to PDSCH, can achieve a Pareto optimal balance between communication and perception.
Conclusion: This study successfully tackled the core issue of false alarm targets in PRS perception in 5G ISAC through the collaborative innovation of DMRS and PRS, with significant advantages: fully compliant with 3GPP standards, directly deployed on existing 5G networks; no additional hardware overhead, no modification to base station configurations, no reduction in positioning accuracy; meanwhile, it improved the maximum detectable range and achieved a Pareto optimal balance in communication and perception through resource optimization.
This solution provides a cost-effective and highly compatible path for the rapid upgrade of ISAC capabilities in existing 5G networks, offering significant reference value for the implementation of 6G ISAC technology. In the future, with further optimization of algorithms in multi-objective and non-line-of-sight scenarios, there is potential for broader commercial applications in fields such as intelligent transportation and smart cities.
